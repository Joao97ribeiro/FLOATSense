# FLOATSense project page

Static project page (Bulma + Plotly), served by GitHub Pages from this branch.

## Anonymized copy for review

`review/` is an anonymized copy of the page (no authors, affiliations,
repository links, citation or resources; data embedded as small scripts
under `review/static/data/`), served through anonymous.4open.science.
Regenerate it after any change to the site with
`python scripts/build_review.py`; the script fails if an identifying
term is left.
